# Contributing rules

Merci de votre intérêt pour contribuer à **Dojo-101** !

1. **Privilégiez le retour d'expérience pratique** : écrivez *« comment vous l'avez fait »* (commandes, captures, cas réels), et non *« comment il faudrait théoriquement le faire »*.
2. **Évitez les doublons** : vérifiez au préalable que le sujet ou l'outil n'est pas déjà couvert dans l'un des 7 dossiers thématiques.
3. **Formatage** : utilisez exclusivement le format `Markdown` (`.md`), respectez les règles de `.markdownlint.json` et placez les images éventuelles dans le dossier `images/`.

---

💡 **Pas le temps de rédiger une Pull Request ?** Vous pouvez également soutenir la maintenance et la création de nouvelles fiches en [devenant Sponsor sur GitHub 💖](https://github.com/sponsors/Aif4thah/) ou en ajoutant une ⭐ au dépôt !
